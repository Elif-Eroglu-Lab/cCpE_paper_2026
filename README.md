# cCpE_paper_2026
Code for the paper "Claudin-dependent clonal expansion couples epicardial activation to regenerative fate acquisition"

Summary:

- clonality_matlab: Fig.2, Fig. 4
- shape_morphometrics: Fig. 3
- junction_protein_levels: Fig. 3
- linear_mixed_effects_model_matlab: Fig. 6 (dynamic mechanical analysis)
- snRNAseq: Fig. 5-7.
- spatial_transcriptomics: Fig. 5-6 (predicted localizations), Fig. 8 (border zone spatial transcriptomics).
- bridge_orientation: Fig. 8 (orientation of ECM scaffolds at the injury site)
